PWA notifications

An installable page for trying the options of showNotification(). Nothing is pushed from a server: the page asks its service worker to show the notification, which is the same call a push handler would make, so what appears is what a real push would look like.

Install

The Install button works where the browser fires beforeinstallprompt (Chromium). Elsewhere use the browser's own menu: on iOS and iPadOS, Share → Add to Home Screen; in Safari on macOS, File → Add to Dock. iOS and iPadOS offer notifications only to the installed app, so install first and continue there.
