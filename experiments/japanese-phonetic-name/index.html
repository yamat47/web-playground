Japanese phonetic name autofill

Chrome fills furigana fields together with the kanji name when the form follows the Chrome for Developers article. This form does.

Before trying it

Chrome fills the furigana fields only from a profile that has a phonetic name. In chrome://settings/addresses, add or edit an address, set the country to Japan, and fill in Phonetic name (よみがな). Then click into 姓 and pick the suggestion.
