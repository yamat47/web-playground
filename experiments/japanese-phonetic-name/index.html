Japanese phonetic name autofill

Chrome fills furigana (phonetic name) fields together with the kanji name. The standard autocomplete tokens (name, family-name, given-name) cover both, so Chrome tells the two apart by the field's name attribute and its <label> text. This form follows the naming from the Chrome for Developers article.

How to try it

  1. Put a phonetic name into your Chrome profile. Open chrome://settings/addresses (Settings → Autofill and passwords → Addresses and more; 設定 → 自動入力とパスワード → 住所やその他の情報). Add an address or pick Edit from the ⋮ menu of an existing one, set the country to Japan, fill 姓 / 名, and fill the Phonetic name field (よみがな). Chrome shows it in hiragana; either script works. Chrome also offers to save the phonetic name the first time you submit a form where you typed one.
  2. Fill the form. Click into 姓 and pick the suggestion. All four split fields, or both full-name fields, should fill at once.
  3. See how Chrome classified each field. Open DevTools, press Cmd+Shift+P (or Ctrl+Shift+P), run Show Autofill (also under More tools → Autofill), then trigger the autofill again. The panel lists every field with its predicted type; the furigana fields should read Alternative family name, Alternative given name and Alternative full name. If you have no saved address, the panel's Show test address data in autofill menu option lets you fill with sample data, which does not include a phonetic name but still shows the classification.

References: the Chrome for Developers article, the Google Japan announcement, and the DevTools Autofill panel docs.
